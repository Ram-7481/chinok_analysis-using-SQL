
# Chinook Data Analysis Using SQL

## Project Overview
This project focuses on analyzing Chinook music store data using SQL to uncover sales performance, customer purchasing behavior, top-selling tracks, artist performance, and genre trends. The analysis was performed using multiple Chinook datasets, including customers, invoices, invoice_items, tracks, albums, artists, and genres tables.

## Objectives
- Analyze sales and customer purchasing behavior.
- Identify top-selling tracks, artists, and genres.
- Evaluate customer spending and purchase patterns.
- Analyze revenue trends across different countries.
- Generate data-driven insights to support strategic decision-making.

## Tools & Technologies
- SQL
- MySQL
- Joins
- CTEs
- Subqueries
- Aggregate Functions
- Window Functions

## Key Analysis Performed
- Top-performing artists and tracks.
- Highest revenue-generating genres.
- Customer purchasing behavior and spending patterns.
- Country-wise revenue analysis.
- Customer-wise sales and purchase frequency.
- Customer segmentation and lifetime value analysis.

## Key Insights
- Identified top-performing artists and tracks based on sales.
- Analyzed customer purchasing and spending patterns.
- Discovered country-wise revenue trends.
- Identified high-value customers based on purchase history.
- Analyzed customer retention and churn patterns.
- Generated actionable insights from historical music store data.

## Conclusion
The project demonstrates strong SQL skills, analytical thinking, and the ability to transform raw music store data into meaningful business insights.
